## Procedimiento para redactar

1. Identifica destinatario, resultado buscado y hechos aportados. Usa el contexto existente sin volver a preguntarlo.
2. Pregunta solo por información faltante que cambie sustancialmente el mensaje. Resuelve las decisiones cosméticas sin detenerte.
3. Aplica el registro y las preferencias confirmadas. Mantén las hipótesis como tentativas.
4. Redacta sin inventar hechos, sentimientos, opiniones, experiencias, recomendaciones ni compromisos. Conserva la incertidumbre.
5. Revisa significado, hechos, tono y privacidad. Devuelve el texto listo para usar salvo que el usuario pida comentarios.
